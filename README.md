Tejaswini B - React + Tailwind Portfolio (starter)

Quick start:
1. Install Node 18+ and npm.
2. cd tejaswini_react_portfolio
3. npm install
4. npx tailwindcss init -p
   - (tailwind.config.cjs provided; if you already ran init, merge content)
5. npm run dev
6. Open http://localhost:5173

Files:
- package.json (dependencies + scripts)
- tailwind.config.cjs
- postcss.config.cjs
- public/index.html
- src/main.jsx
- src/App.jsx
- src/index.css
